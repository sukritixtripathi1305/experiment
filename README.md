# Just Start

A tiny dependency-free web app that pushes you to finish the tasks you keep putting off.

- Tasks are ranked by an avoidance score (age, dread, skips, due date); the most-avoided one is always front and center.
- "Start 2-minute sprint" lowers the barrier; when it ends you can continue for 25 minutes or finish.
- Pip, a little mascot, reacts to your progress (sleepy, hopeful, sad when you dodge, party on completion) and pokes you with gentle reminders.
- Streak and done count. Data lives in `localStorage`.

Run: `python3 -m http.server` and open http://localhost:8000
